The assignment was originally written in Romanian and I tried my best to translate it in a readable form in English. I posted the assignment descriptions in both languages (it's quite hard to summarize a large pdf so to best understand the meaning of the project the pdf's are the way to go)
Assembly x86 AT&T – Memory Segment Simulation

**🔍 Overview**

This project simulates memory segment operations using x86 AT&T Assembly. The program performs matrix and array operations at a low level, showcasing skills in memory manipulation and debugging.

**🚀 Features**

Low-level memory management

Matrix and array operations using Assembly

**🛠️ Technologies Used**

x86 AT&T Assembly

GNU Assembler / GDB Advanced Debugging

**📥 Installation & Usage**

Clone the repository:
```
git clone https://github.com/stefmin/Assembly_Memory_Sim.git
cd Assembly_Memory_Sim
```

To run the program:

add executable permissions to the compiled binaries or compile the source code yourself first
use a test file and redirect it to standard input for the compiled binaries
